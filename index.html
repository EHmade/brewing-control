About & References

This tool is designed for coffee brewing education, repeated brew testing, and comparative analysis. It visualizes brew strength (TDS), extraction yield, and brew ratio relationships using the brewing control chart framework originating from E. E. Lockhart's work.

The built-in Classic Filter profile uses a default reference range of 18–22% extraction yield and 1.15–1.35% TDS, informed by published SCA brewing materials. This range is provided as a starting reference only.

Target ranges, chart scales, brew ratios, and liquid-retention assumptions are configurable. User-defined targets and chart ranges should not be interpreted as established sensory-quality standards or physical limits.

When beverage mass is not entered, the tool estimates it from brew water, measured TDS, and the configured liquid-retention value using a mass-balance relationship. The built-in Classic Filter uses 2.1 as its default liquid-retention reference; this value remains configurable. Calculated extraction yield therefore depends on the measurements and assumptions provided by the user.

Independent project. This project is independently developed and is not affiliated with or endorsed by the Specialty Coffee Association. No SCA logo or SCA chart artwork is included.

Data & privacy

Brew records, class data, profiles, and settings are stored locally in the browser by this application. The application does not transmit entered brew or class data to an application backend. This does not cover ordinary hosting access logs or actions explicitly initiated by the user, such as export or sharing. JSON export is available for manual backup and transfer.

References

E. E. Lockhart. The Soluble Solids in Beverage Coffee as an Index to Cup Quality. Coffee Brewing Institute, 1957.
Specialty Coffee Association. Coffee Brewing Control Chart, Version 3, revised March 2019.
J.-X. Guinard et al. A new Coffee Brewing Control Chart relating sensory properties and consumer liking to brew strength, extraction yield, and brew ratio. Journal of Food Science 88(5), 2023. DOI 10.1111/1750-3841.16531.

Changelog

Earlier development history is condensed to major user-facing and architectural milestones.

v4.3.5 · Public-release preparation

  • Renamed user-facing terminology to Coffee Brewing Control / Brewing Control Chart.
  • Added About & References, privacy/context notes, an in-app changelog, and visible app version information.
  • Refined chart zoning into semantic Strong/Weak and Under/Over overlay bands while keeping the sage target and smoky-plum brew-ratio lines.
  • Corrected automatic beverage-mass estimation and Brew Ratio guide lines to use the full mass-balance relationship, and updated the Classic Filter liquid-retention default from 2.0 to 2.1.
  • Kept legacy storage and backup identifiers for backward compatibility.

v4.3.4.1

  • Added current class/session context to Class chart filters.
  • Made roster exclusion reversible while preserving historical records and student IDs.

v4.3.4

  • Added reusable Class practice sessions with independent per-session records.
  • Added schema v2 migration and preserved earlier Class records as migrated sessions.
  • Updated Class chart/export context to the active session.

v4.3.3

  • Added Quick experiment name/note, ΔEY/ΔTDS tooltips, desktop/mobile chart interaction, and PNG chart output.
  • Added copy/save/share workflows with in-app preview fallback for restricted environments.

v4.3.2

  • Separated live Quick input from committed saved attempts.
  • Added live-point styling, saved-to-live preview paths, and dynamic per-attempt feedback.

v4.3.1

  • Strengthened JSON backup export with visible preview, clipboard fallback, and OS save-dialog support where available.

v4.3

  • Added full JSON export/import, schema versioning, and a storage-adapter layer.
  • Moved class administration into Settings and replaced browser prompt/confirm dialogs with in-app dialogs.

v4.2

  • Added saved Quick attempt paths, target-point guidance, independent Quick/Class feedback controls, and multiple classes.

v4

  • Separated brew notes from instructor feedback.
  • Added dynamic target classification, Class progression arrows, configurable chart bounds/ratio lines, and brewing profiles.

v3

  • Added target-relative STRONG / WEAK / UNDER / OVER chart regions and point hover details.
  • Replaced the earlier Golden Cup chart label with the neutral TARGET label while keeping the target range configurable.

v2

  • Introduced separate Quick and Class workflows, student rosters, sequential records, chart filtering, and browser-local persistence.

Initial prototype

  • Single-file browser calculator for brew measurements, extraction yield, TDS, dissolved solids, and brew ratio.
  • Added automatic beverage-mass estimation and the first live brewing-control chart.
